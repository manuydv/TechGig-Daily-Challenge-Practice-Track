# New In Season — favorites folder

Drop your favorite photos here — the ones you want featured as this
season's highlights. When you tell Claude they're in, this folder is
what gets used to update:

1. **"New This Season"** (the Signature Pieces section) — rebuilt with
   an even split of bags and jackets, drawn from your favorites here.
2. **The homepage hero slideshow** — refreshed to include jacket shots
   alongside the bag shots it currently shows.

## Folders
- `bags/` — your favorite bag photos for this season
- `jackets/` — your favorite jacket photos for this season

## Tips for consistent results
- Aim for roughly equal numbers in `bags/` and `jackets/` — that's what
  keeps "New This Season" balanced between the two product lines.
- Any file name is fine (e.g. `favorite1.jpg`) — just say once you've
  added photos and Claude will take it from there (name, description,
  material and price for each piece can be given then, or Claude will
  ask if anything's missing).
- These can be the same files as ones already sitting in a category
  folder (e.g. `images/bags/womens/tote-shopper/`) — this folder is just
  a curation shortlist, not a replacement for the category folders.
- Delete the `.gitkeep` file in a subfolder once it has real photos in
  it — it's only there so Git tracks the empty folder.
