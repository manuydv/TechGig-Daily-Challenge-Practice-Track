# Jacket photo folders

Drop product photos into the matching category folder below. When you're
ready, tell Claude and the HTML/CSS will be updated to display them —
each category card in the "Leather Jackets" section will show your real
photos instead of the line-art icon (exactly like the bag categories).

## Tips for consistent results
- Any file name is fine (e.g. `jacket1.jpg`, `product-01.png`) — just say
  which folder(s) you've added photos to.
- Studio shots on a plain light-grey background (like the ones already
  used in "Signature Pieces") blend into the site cleanly with no extra
  editing needed.
- A few photos per category is enough to start; more can be added later.
- Delete the `.gitkeep` file in a folder once it has real photos in it —
  it's only there so Git tracks the empty folder.
