# Jacket photo folders

Unlike the bags (which are split into categories like Tote & Shopper,
Crossbody, etc.), jackets are just split by gender — drop photos straight
into the matching folder below. When you're ready, tell Claude and the
HTML will be updated to show your real photos in the "Leather Jackets"
section instead of the line-art icon.

## Women's Jackets — `womens/`
Any leather jacket photos for women — biker, bomber, trench, shearling,
etc. — go straight in this one folder.

## Men's Jackets — `mens/`
Any leather jacket photos for men go straight in this one folder.

## Tips for consistent results
- Any file name is fine (e.g. `jacket1.jpg`, `product-01.png`) — just say
  which folder(s) you've added photos to.
- Studio shots on a plain light-grey background (like the ones already
  used in "Signature Pieces") blend into the site cleanly with no extra
  editing needed.
- A few photos is enough to start; more can be added later.
- Delete the `.gitkeep` file in a folder once it has real photos in it —
  it's only there so Git tracks the empty folder.
