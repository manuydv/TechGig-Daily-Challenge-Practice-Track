# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v56.0.0/ before writing any code.

Pinned to SDK 56 (not the newer 57) because the Expo Go app on the App
Store/Play Store hadn't picked up SDK 57 support yet when this was pinned.
If you're bumping this later, confirm Expo Go actually supports the target
SDK first — check https://expo.dev, or just try it: a too-new SDK produces
"Project is incompatible with this version of Expo Go" on device.
